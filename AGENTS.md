# AGENTS.md

## Overview

Personal dotfiles repository. Each top-level directory maps to a specific location in `~/`.

## Structure

```
dotfiles/
├── nvim/           # → ~/.config/nvim/
├── agents/         # → ~/.agents/
├── Brewfile        # Homebrew dependencies
├── Makefile        # install/uninstall
├── install.sh      # Bootstrap script for new machines
└── README.md
```

## How it works

- `make install` creates symlinks: `~/.config/nvim` → `dotfiles/nvim`, `~/.agents` → `dotfiles/agents`
- `make uninstall` removes the symlinks
- `install.sh` clones the repo (if missing) and calls `make install`

## Nvim

Package: `nvim/` → `~/.config/nvim/`

Plugin manager: [lazy.nvim](https://github.com/folke/lazy.nvim) (auto-bootstrapped).

### Architecture

```
nvim/
├── init.lua                  # Entry: sets leader, clipboard, lazy.loader, requires config
├── stylua.toml               # Formatting rules (tabs, width 2)
├── lazy-lock.json            # Auto-generated by lazy.nvim
└── lua/
    ├── config/
    │   ├── init.lua          # Bootstrap lazy.nvim + lazy.setup
    │   ├── options.lua       # vim.opt settings
    │   ├── keymaps.lua       # All keybindings
    │   └── autocmds.lua      # Yank highlight
    └── plugins/
        ├── ui.lua            # rose-pine, lualine, bufferline, oil.nvim
        ├── editor.lua        # snacks, gitsigns, Comment, mini.pairs
        ├── lang.lua          # treesitter, mason, nvim-cmp + LuaSnip, lspconfig, conform
        └── data.lua          # molten-nvim, image.nvim, vim-table-mode
```

### Plugin categories

| File | Domain | Plugins |
|------|--------|---------|
| `ui.lua` | Interface | rose-pine, lualine, bufferline, oil.nvim |
| `editor.lua` | Editing | snacks (picker+words+notifier+dashboard+statuscolumn+terminal), gitsigns, Comment, mini.pairs |
| `lang.lua` | Languages | treesitter (parsers auto-installed), mason*, nvim-cmp + LuaSnip, lspconfig, conform |
| `data.lua` | Data science | molten-nvim (lazy: markdown/python/quarto), image.nvim, vim-table-mode |

### Adding a plugin

1. Identify which domain file it belongs to (or create a new `lua/plugins/*.lua`)
2. Add a lazy.nvim spec to that file
3. Each file returns a table of specs: `return { { "author/plugin", opts = {} }, ... }`

### Theme

[Rosé Pine](https://github.com/rose-pine/neovim) dark variant (`main`).
Applied in `plugins/ui.lua` via lazy.nvim.

### Terminals

A single terminal implementation: `snacks.terminal` (already loaded by snacks).
- `<leader>t` (normal/terminal mode) toggles a bottom split (`count` for more terminals)
- `<Esc><Esc>` leaves terminal mode

Terminal buffers use the `snacks_terminal` filetype and are excluded from lualine.

### Data science (molten)

Requires a Python venv with `pynvim` + `jupyter`; `make venv` creates it at
`~/.local/share/nvim/molten-venv` (referenced by `vim.g.python3_host_prog`).

Inside a markdown buffer: `:MoltenInit python3`, then `<leader>r*` keymaps.

## Agents

Package: `agents/` → `~/.agents/`

Contains 3 AI agent skills (`frontend-design`, `shadcn`, `vercel-react-best-practices`)
used by OpenCode and nvim's dotagent plugin.

### Skill structure

Each skill is a directory under `skills/` containing:
- `SKILL.md` — Main skill definition (YAML frontmatter + markdown instructions)
- Optional: `evals/`, `references/`, `templates/`, `rules/`, `assets/`, `scripts/`

### Adding/removing skills

Skills are managed externally (via OpenCode CLI). The `.skill-lock.json` tracks installed skills.
To update skills in the repo after external changes, re-copy the `~/.agents/` directory.

## Brewfile

Dependencies installed via `brew bundle`:
- `neovim` — Editor
- `ripgrep` — Search (snacks picker grep)
- `fd` — File discovery
- `sqlite3` — Optional memory database
- `imagemagick` — `magick_cli` processor for image.nvim
- `stylua` — Lua formatter (conform)
- `prettierd` — JSON/TS/CSS/HTML formatter (conform)

## Conventions

- **Indentation**: tabs, width 2 (`.editorconfig`)
- **Git**: no `.DS_Store`, no `*.local` files tracked
- **Secrets**: not tracked. API keys via env vars (`DEEPSEEK_API_KEY`)

## Maintenance

```bash
# Update brew deps
brew bundle --file Brewfile

# Create/refresh the molten python venv
make venv

# Refresh lazy.nvim plugins (inside nvim)
:Lazy sync
```
